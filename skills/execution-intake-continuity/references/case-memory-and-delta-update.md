## 一、项目记忆原则

项目记忆服务于同一宗申请执行人代理案件的持续办理。它不是案件事实的自动认证，也不能替代原件、正式文书和律师判断。

遵守以下规则：

1. 已核实事实、客户陈述、待核事项、材料缺口和律师决定分开保存。
2. 每条已核实事实保留材料定位和律师确认状态。
3. 客户陈述在正式建项后仍可保持待核，不因进入项目而升级。
4. 新材料只改变它实际支持、否定或冲突的原记录。
5. 保留历史版本和变化原因，不覆盖谈案阶段的原始记录。
6. 实际未写入文件或宿主记忆时，不声称已保存。
7. 项目记忆使用自己的当前编号，并保留谈案原编号映射。不得因编号相同就把“正式材料可支持”自动升格为“已核实事实”。

## 六、版本和落盘状态

版本至少记录：

- 版本号；
- 更新日期；
- 更新批次；
- 受影响事项；
- 保持不变事项；
- 更新人；
- 律师复核状态；
- 实际文件路径或“尚未确认落盘”。

不要用“已生成”替代“已保存”，不要用“已读取”替代“内容已核实”，不要用“项目记忆已更新”替代真实文件写入回执。
