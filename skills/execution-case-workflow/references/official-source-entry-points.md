# 现行官方法源核验入口

## 使用规则

本文件只提供截至 2026-08-11 已复核可访问的官方入口，不预填个案结论。每次使用专项方向时重新核验：

1. 规范全称和发布机关。
2. 文号、公布和施行信息。
3. 是否存在修订、废止、过渡规则或新的配套规范。
4. 具体条文和个案事实是否匹配。
5. 全国规则、地方规范和受理法院要求是否需要区分。
6. 查询日期、官方链接或数据库定位。

无法完成上述核验时，法源状态写为 `待核验`，不得凭模型记忆给出确定期限、要件或程序结论。

## 一、变更、追加执行当事人

- [最高人民法院关于民事执行中变更、追加当事人若干问题的规定](https://gongbao.court.gov.cn/Details/99c0f6d9535f31fbfd526f8a3cce03.html)
- 官方来源：最高人民法院公报。
- 使用时核验：拟援引的具体情形、程序救济、现行效力和个案证据，不沿用旧 PPT 的情形归纳作为完整法律结论。

## 二、执行异议之诉

- [最高人民法院关于审理执行异议之诉案件适用法律问题的解释](https://gongbao.court.gov.cn/Details/7bfbf4ce3233e84b64fb32d345a991.html)
- [最高法民一庭、执行局负责人答记者问](https://www.court.gov.cn/zixun/xiangqing/471711.html)
- 官方来源：最高人民法院公报、最高人民法院。
- 使用时核验：异议类型、程序身份、具体请求、受理和举证问题，不从历史课件复制固定期限或处理结论。

## 三、债权人代位权与撤销权

- [中华人民共和国民法典](https://flk.npc.gov.cn/detail?fileId=&id=ff808081729d1efe01729d50b5c500bf&title=%E4%B8%AD%E5%8D%8E%E4%BA%BA%E6%B0%91%E5%85%B1%E5%92%8C%E5%9B%BD%E6%B0%91%E6%B3%95%E5%85%B8&type=)
- [最高人民法院关于适用《中华人民共和国民法典》合同编通则若干问题的解释](https://gongbao.court.gov.cn/Details/f4722cf61c92a585f04b2ecd334f5b.html)
- 官方来源：国家法律法规数据库、最高人民法院公报。
- 使用时核验：基础债权、相对人权利、怠于行使、处分行为、影响债权实现、相对人主观状态、行使范围、程序和时间效力等个案要素。

## 四、拒不执行判决、裁定相关候选

- [最高人民法院、最高人民检察院关于办理拒不执行判决、裁定刑事案件适用法律若干问题的解释](https://gongbao.court.gov.cn/Details/0db85b81c8c9d7222e2795b3a5da95.html)
- [最高人民法院、最高人民检察院、公安部关于办理拒不执行判决、裁定刑事案件若干问题的意见](https://www.court.gov.cn/zixun/xiangqing/469121.html)
- 官方来源：最高人民法院系统、最高人民法院。
- 使用时核验：执行义务、履行能力、拒绝履行行为、情节、证据和程序路径。不得只因未履行、限高、失信或出现财产线索就作刑事定性。
